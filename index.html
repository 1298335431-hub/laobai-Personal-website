01 / 梦境记录

梦卡

Dreamcard

把醒来后零散的梦，留成一张可以保存的卡片。

解决的问题
梦醒后的片段很快消失，普通文字记录也很难保留当时的感受。
我做的工作
梳理梦境输入、梦象确认、参考性解读和梦卡生成流程，并完成开源项目的二次开发与上线。
当前状态
已可在线体验；曾作为作品参加知乎活动。

02 / 会前准备

MeetingPrep

选择会议模板，导入资料，提前把背景和讨论方向讲清楚。

解决的问题
会前资料分散在 PRD、历史记录和日历里，参会者常在会议现场才开始补背景。
我做的工作
设计会议模板、PRD 与历史记录导入、会前 Brief 生成和来源核对流程，并接入飞书与 DeepSeek。
当前状态
已上线验证，使用邀请码访问。

03 / 图片社交

贴贴

Tietie

从一个 Skill 开始创作，再让图片成为社交的开场白。

解决的问题
图片生成通常停在“出图”，创作之后缺少继续修改、分享和互动的链路。
我做的工作
把开源 Skill 定义为创作能力入口，串起生成、修改、作品分享和“碰一碰”互动。
当前状态
内测中；下一阶段会在 GitHub 上架 Skill 仓库。
